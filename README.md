Password Strength Checker

1. Project Title

Password Strength Checker Using Python

2. Aim

To check the strength of a password based on different security conditions using Python.

3. Description

The Password Strength Checker is a Python program that evaluates a password by checking its length and character types. It checks whether the password contains uppercase letters, lowercase letters, numbers, and special characters.

4. Features

- Checks password length.
- Identifies uppercase letters.
- Identifies lowercase letters.
- Checks for numeric digits.
- Checks for special characters.
- Displays the password strength based on the conditions satisfied.

5. Requirements

- Python 3
- Notepad or VS Code

6. How to Run

1. Save the program as "password_strength_checker.py".
2. Open Command Prompt or the VS Code terminal.
3. Run the command:

python password_strength_checker.py

4. Enter a password when prompted.

7. Sample Output

===== PASSWORD STRENGTH CHECKER =====

Enter password: Test@12345

Password Length: Valid
Uppercase Letter: Present
Lowercase Letter: Present
Number: Present
Special Character: Present

Password Strength: Strong

Note: The output depends on the password entered and the program's scoring rules.

8. Applications

- Basic password security awareness
- Password strength evaluation
- Learning Python string handling and conditions

9. Conclusion

The Password Strength Checker demonstrates how Python can evaluate password characteristics and help users understand basic password security.
